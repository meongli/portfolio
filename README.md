# 문헌정보 포트폴리오

문헌정보학 전공 졸업예정자의 실무 경험, 수상, 개인 프로젝트를 강점별로 정리한 포트폴리오 웹페이지입니다.

## 파일
- `index.html` — 웹사이트로 보이는 페이지 (GitHub Pages)
- `portfolio-data.js` — 내용(자기소개, 경험, 강점). 여기만 고치면 됩니다
- `portfolio-style.css` — 디자인
- `build.js` — 데이터를 읽어 페이지를 새로 만드는 스크립트

## 내용 고치는 법
1. `portfolio-data.js`를 고칩니다.
2. `node build.js`를 실행하면 `index.html`이 새로 만들어집니다.
